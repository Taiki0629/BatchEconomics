# さくらのAI Engine 利用規約（プロジェクト内ルール）

情報源: 公式マニュアル・サービスサイト・公式 OpenAPI 仕様（2026-07-27 確認）。
ローカル控え: `90_resources/official_docs/`（OpenAPI 仕様 `ai-engine-inference-openapi.yaml` と出典メモ）。
**このファイルにない仕様を推測で書かないこと。不明点は OpenAPI 仕様かコントロールパネルで確認する。**

## 認証（確認済み）

- コントロールパネル（`https://secure.sakura.ad.jp/ai/`）で「アカウントトークン」を作成
- トークンは `<UUID>:<シークレット>` のペア形式
- リクエストヘッダー: `Authorization: Bearer <トークン>`
- トークンは環境変数 `SAKURA_API_KEY`（`.env`）から読む。**コード・ログ・リポジトリに絶対に埋め込まない**

## chat/completions の主要パラメータ（OpenAPI 仕様より）

`model`（必須）, `messages`（必須）, `max_tokens`, `temperature`, `stream`, `tools`, `tool_choice`

- 「利用するモデルによってはサポートされていないパラメータもある」と公式に明記あり
- `response_format`（JSON モード）や `seed` は仕様に記載なし → **要確認**（使う場合は実機で挙動確認してから）
- レスポンスは `choices` / `usage` / `model` を含む JSON（usage からトークン数を取得してログに残す）

## 無償枠（確認済み・最重要）

| API | 無償枠 |
|---|---|
| Chat completions | **3,000 リクエスト/月** |
| Embeddings | **10,000 リクエスト/月** |
| 音声認識 | **50 リクエスト/月** |
| TTS | **50 リクエスト/月** |
| RAG（ドキュメント） | **無償枠なし**（利用開始時点で課金対象。本プロジェクトでは使わない） |

- **基盤モデル無償プラン**: 無償枠超過時は**自動課金されずレート制御がかかる**。プランが勝手に切り替わることもない（公式明記）
- 従量課金プランでは超過分が課金される（参考単価: gpt-oss-120b 入力 0.15円/万トークン・出力 0.75円/万トークン）
- 無償枠は翌月に自動リセット

## 呼び出し前の消費見積もりルール（プロジェクト安全弁）

**無償枠を消費する実行は、事前に以下を提示して taiki さんの承認を得るまで実行禁止。**

1. 目的（何の実験か、run_id）
2. 消費リクエスト数の内訳（水準数 × 試行数 × リトライ見込み）
3. 実行後の累計消費見込みと残枠（`/budget` で実績確認）
4. 中断条件(consecutive failures 等)

小規模試走（スモークテスト）も例外ではない。1リクエストでも事前見積もりの対象。

## リトライ規約（プロジェクト内ルール）

OpenAPI 仕様でエラーとして定義されているのは `400` / `401` / `429 (Rate limited)` / `500` / `504`。公式のリトライ推奨手順は文書化されていないため、以下は本プロジェクトの規約:

- **429 / 5xx**: 指数バックオフでリトライ。初回 2 秒、倍々で最大 60 秒、**上限 5 回**。`Retry-After` ヘッダーがあれば優先して従う
- **400 / 401**: リトライしない（リクエスト自体の誤り。即座に停止して原因調査）
- リトライも 1 リクエストとして無償枠を消費する前提で数え、**すべての試行（attempt）をログに記録する**
- 429 が連続する場合は無償枠超過のレート制御の可能性が高い。**3 回連続で 429 になったら実験全体を停止**し、`/budget` で消費状況を確認する
- レート制限の具体的な閾値（req/秒）は非公開 → **要確認**。安全側として、リクエスト間に最低 1 秒のインターバルを入れる

## 実装規約

- すべての API 呼び出しは `30_development/` の共通クライアント経由。リトライ・レート制御・ログ記録をそこに集約する
- OpenAI 互換形式なので `openai` SDK の `base_url` 差し替えでも呼べるはずだが、依存を減らすため素の `httpx`/`requests` を推奨（P2 で最終決定）
