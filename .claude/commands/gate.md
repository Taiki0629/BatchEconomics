---
description: 現フェーズのレビューゲート（セルフレビュー）を実行する
---

現在のフェーズのレビューゲートを実行してください。**R-00〜R-04 は Claude Code 自身によるセルフレビューであり、taiki さんのレビューは最終成果物（R-05）のみ**です。

1. `10_management/TASKS.md` から現在のフェーズと対応するゲート番号（R-0X）を特定する
2. そのフェーズの成果物がすべて揃っているか実ファイルを確認する。未完了タスクがあれば先に完了させる
3. サブエージェント（Agent ツール）に成果物を**批判的に**レビューさせる。観点: 論理の飛躍、数値・見積もりの計算誤り、根拠のない断定、再現性の欠落、CLAUDE.md の規約違反
4. 指摘に対して修正を行い、指摘内容・修正内容・見送った指摘（理由付き）を `10_management/REVIEW_LOG.md` に R-0X として記録する
5. `TASKS.md` のフェーズ進捗を更新して次フェーズへ進む

**ただし以下の場合はセルフレビュー後も停止して taiki さんの入力を待つこと:**
- 次の作業が無償枠を消費する場合（消費見積もりを提示して承認を得る）
- U-タスク（taiki さんにしかできない作業）がブロッカーになっている場合
- R-05（最終成果物）に到達した場合（taiki さんのレビューを依頼する）
