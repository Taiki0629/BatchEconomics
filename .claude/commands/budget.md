---
description: API 消費リクエスト数を実験ログから集計し残枠を表示する
---

さくらのAI Engine の無償枠の消費状況を集計してください。

1. `40_test/logs/` 以下の JSONL ログ（1リクエスト1行）をすべて走査する
2. 当月（ログの timestamp が今月のもの）について、API 種別ごとにリクエスト数を集計する
   - リトライ（attempt >= 2）も1リクエストとして数える（枠を消費するため）
   - HTTP ステータスに関わらず、送信した分はすべて数える
3. 無償枠と突き合わせて残枠を表示する:
   - Chat completions: 3,000 req/月
   - Embeddings: 10,000 req/月
   - 音声認識: 50 req/月
   - TTS: 50 req/月
4. 表形式で「消費 / 上限 / 残り / 消費率」を表示する
5. 消費率が 70% を超えている種別があれば ⚠️ を付けて警告する
6. ログがまだ無い場合は「消費 0（ログなし）」と表示する

集計は表示のみ。このコマンドで API を呼んではいけない。
