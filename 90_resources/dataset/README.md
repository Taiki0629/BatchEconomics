## 構成

- 96 アイテム = positive 48 / negative 48（均衡）
- 難度: easy 60（明確な賞賛・不満。positive 30 / negative 30）+ hard 36（否定表現・逆接・条件付き評価・皮肉。positive 18 / negative 18）
- 96 はバッチサイズ水準 {1, 2, 4, 8, 16, 32, 48, 96} すべてで割り切れる
- ドメインは通販・飲食・宿泊・家電・アプリ・書籍などに分散
- ファイル内の並びは 4 群（easy/hard × pos/neg）の周期的インターリーブ。実験時は trial ごとにシード付きシャッフルするため、この並び自体は使われない

## ラベル妥当性検証（2026-07-28 実施）

- 独立サブエージェントによる**ブラインド分類**（正解ファイル非開示）で 96/96 件が想定ラベルと一致
- ただし 3 件（d-038, d-076, d-096）に「極性が曖昧になり得る」との指摘 → 難度を保ちつつ極性が一意になる文面に差し替え済み（差し替え後の全文が現ファイル）
- 差し替え後の再検証は試走 p3-001 の難度確認（B=1 正解率）で兼ねる

## 注意

- LLM 作の「紛らわしい」文は LLM に紛らわしくない恐れがある（レビュー指摘14）。試走で B=1 正解率が 98% 超なら hard 36 件を差し替える手順が設計 §2.2 に定義済み
