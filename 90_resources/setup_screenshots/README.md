## 加工内容（公開前の匿名化）

すべて元画像に対して以下を機械的に適用済み。加工スクリプトは `30_development/mask_screenshots.py`。

1. **上部175pxをクロップ** — ブラウザのタブ・アドレスバー・ブックマークを完全に除去（URLに含まれるトークンIDや、個人のブックマーク・開いているタブの情報を排除）
2. **右上の「会員ID:プロジェクト名」バッジを塗りつぶし**
3. **`03` はアカウントトークンID（UUID）も塗りつぶし**

塗りつぶし領域には `(masked)` と表示し、加工の事実が読者に分かるようにしている。

## 公開しなかった画像について

会員登録フロー（メールアドレス登録・認証コード入力・**会員情報入力**）と、さくらのクラウド ホーム／会員メニューのスクリーンショットは**公開対象から除外**した。

理由:
- 会員情報入力画面には氏名・メールアドレス・生年月日・性別・住所が含まれ、マスクすると画面の大半が黒くなり資料価値が残らない
- アカウント作成手順そのものは[公式マニュアル](https://manual.sakura.ad.jp/cloud/payment/signup.html)が扱っており、記事で再掲する必要がない

元画像は `31_環境構築/` にあるが、**`.gitignore` 済みで公開リポジトリには含まれない**。
